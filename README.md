# fear-dmmm-nosferatu-wrath-of-malachi
## F.E.A.R - Dark Messiah of Might and Magic — Nosferatu Wrath of Malachi Remake
A twin-game total conversion project: one remake built around gunplay (F.E.A.R.) and one built around swordplay only (Dark Messiah of Might and Magic), both using the randomized castle layout, rescue loop, and time pressure of Nosferatu: Wrath of Malachi as their shared design spine.

## Half-Life 2 Source SDK
This repository holds the engine and game source code  - the game first released in 2004 as *Half-Life 2*. The code has been modernized to C++20, built with CMake and Clang, with cross-platform support for Windows x64 and Linux x64.

## LithTech Jupiter EX Engine
The LithTech Jupiter EX, the engine Monolith Productions used for F.E.A.R. (2005) and Condemned: Criminal Origins . A GPL release of the Jupiter EX engine exists and serves as the reference point for the gunplay half of this project . The original F.E.A.R. SDK provides server/client game DLL source, client FX source, and engine API access .
